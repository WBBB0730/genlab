# 库集中放在配置指定的目录，不放进代码项目

库放在配置（`~/.config/genlab/.env` 的 `GENLAB_LIBRARY`）指定的一个固定目录里（例如家目录下单独一个文件夹），所有代码项目共用；根目录未配置时直接报错，不回落到任何默认位置。代码项目要用某个版本时，由 agent 把产物复制过去。

库里的成品和生成记录是要长期保留的东西。如果放进代码项目并加入 `.gitignore`，它们就不再受 git 保护：`git clean`、重新 clone、删掉项目都会连带删除；agent 常在临时 worktree 里工作，worktree 清理时也会一起删掉。而且代码项目真正要用的文件仍得复制到不被忽略的位置，放进项目省下的只是一次复制。

## Considered Options

- **放进代码项目，库文件夹里自带一个只忽略自身的 `.gitignore`，在 worktree 里运行时改存到主仓库**：成品就在代码旁边，很多 agent 默认只能读写当前项目，放在项目里不用另开权限；但除了上述丢失风险，改存主仓库同样超出 agent 默认的读写范围，而且只有在那个项目里运行工具才会补收它未完成的生成。被否。

## Consequences

- 每个 agent 需要开放一次库目录的读写权限（沙箱配置）。
- 代码项目通过项目关联对应到库里的项目（见 ADR-0006）。
- 库里的历史与未完成的生成集中在一处，任何命令运行时都能统一补收。
