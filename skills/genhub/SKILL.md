# genhub

命令行工具 `genhub`：调用 kie.ai 上的任意媒体模型，产物与完整生成记录保存在本机的库里，按当前代码项目自动归入库里的项目。首次使用前运行 `genhub init` 配置 API Key 与库目录。

## 概念

- **素材**：库里的一个创作单元，用「文件夹/素材名」指定（如 `角色/主角立绘`），名字在所在文件夹内唯一；类型由模型决定（image / video / audio）。
- **版本**：素材的一个产物，版本号在素材内连续递增；状态为 generating / ready / failed。
- **当前版本**：素材选定的那一版，新素材默认取第一个成功的版本。

## 选模型、看参数

1. `genhub models --kind image|video|audio [--search <关键词>]` 列出模型（来自 kie 模型目录）。
2. `genhub models <模型>` 输出价格与参数表：参数名、类型、可选值、是否必填、说明。**参数名以这里为准，不要凭记忆填。**
3. 文生与图生常是两个模型（如 `…-text-to-image` / `…-image-to-image`），按是否带输入图选择。

## 生成

- 新素材：`genhub create <素材> -m <模型> -p <参数>=<值> ... [-n <任务数>]`
- 已有素材再生成：`genhub generate <素材> -m <模型> -p ...`
- 重新生成（沿用某版本的模型与参数，覆盖部分）：`genhub generate <素材> --from <版本> -p <要改的参数>=<值>`
- AI 编辑：`genhub edit <素材> <版本> [-m <模型>] -p <源文件参数>=@source -p ...`（不指定模型时沿用该版本的模型）
- 失败重试：`genhub retry <素材> <版本>`

参数写法：

- `-p key=value`：字符串；数字、布尔、数组按参数表自动转换。
- `-p key:=<JSON>`：直接给 JSON 值，如 `-p duration:=5`、`-p speakers:='[{"voice":"x"}]'`。
- 同一个键写多次即数组：`-p image_urls=@a.png -p image_urls=@b.png`。
- `@<路径>`：本机文件，工具会上传并换成地址；库里的产物直接用它的 `file` 路径。
- `@source`：AI 编辑的源版本文件，只能用在 `edit`。
- 值以 `@` 开头又不是文件时写 `@@`。

## 等待与取用

- 生成类命令默认最多等 90 秒；输出 `"pending": true` 时用 `genhub wait <素材>` 继续等（可加 `--timeout <秒>`）。一次提交多个时用 `--no-wait`，再 `genhub wait` 等全部。
- 输出里每个版本的 `file` 是产物的绝对路径。一个任务可能产出多个版本（如音乐一次 2 首）。
- 用户选定后 `genhub use <素材> <版本>` 设为当前版本；需要放进代码项目时自行复制该文件。

## 其他命令

- `genhub list [文件夹] [--kind ...]`：先看已有素材与文件夹，新素材沿用已有的文件夹分法。
- `genhub show <素材>`：全部版本、生成输入（模型、参数、参考输入、源版本）与文件路径。
- `genhub import <素材> <文件>`：把已有文件导入为新素材的 v1，之后可对它做 AI 编辑。
- `genhub delete <素材> <版本>`：只能删没有派生版本的版本，素材至少保留一个版本。
- `genhub project [名字]`：查看或登记当前代码项目对应的项目。报「未登记」时，向用户确认名字后登记。

## 规则

- 生成会消耗 kie 积分：先看 `genhub models <模型>` 的价格，任务数、分辨率、时长按需设置。
- 不手动修改库里的 `asset.json`；改名、移动、删除整个素材由用户在 Finder 里操作。
- 输出为 JSON；错误在 stderr 的 `{"error": ...}`，警告在 `{"warning": ...}`。
