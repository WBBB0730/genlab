# genlab 使用说明

调用 kie.ai 上的媒体模型生成图片、视频、音频，产物与完整生成记录保存在本机的库里。

下文的 `genlab` 均可写作 `npx -y genlab@latest`（推荐，每次都用最新版本）。

## 概念

- **项目**：库里最外层的分组。当前目录用 `genlab project link` 关联到一个项目后，素材命令都作用于它；`--project` 临时指定其他项目，不改关联。
- **默认项目**：内置的 `default`，一直存在，放不属于任何代码项目的素材。
- **素材**：项目里的一个创作单元，用「文件夹/素材名」指定，文件夹可省略（如 `characters/hero`、`logo`）；类型由模型决定：image / video / audio。
- **版本**：素材的一个产物，版本号在素材内递增；状态为 generating / ready / failed。
- **当前版本**：素材选定的那一版，新素材默认取第一个成功的版本。

## 流程

1. `genlab project` 看当前目录关联的项目。没有关联时先关联：属于某个代码项目就关联到对应的项目，库里还没有就先 `genlab project create`；不属于任何代码项目（家目录、临时目录、下载目录等）就关联到 `default`；判断不了时问用户，不要为了省事把属于某个项目的素材放进 `default`。
2. `genlab list` 看已有素材与文件夹，新素材沿用已有的文件夹分法。
3. `genlab models --kind <类型> [--search <关键词>]` 找模型，`genlab models <模型>` 看价格与参数表。参数名以参数表为准，不凭记忆填。文生与图生常是两个模型（`…-text-to-image` / `…-image-to-image`），按是否带输入图选择。
4. 用户没指定模型时，为新素材的第一次生成挑 2–3 个候选（模型、价格、特点）请用户选；同一素材之后的生成默认沿用该模型，不再询问。
5. `create` / `generate` / `edit` 发起生成。输出 `"pending": true` 时用 `genlab wait` 继续等；一次提交多个时用 `--no-wait`，再用 `genlab wait` 等全部。
6. 生成完向用户汇报使用的模型（版本的 `model`）、消耗的积分（各版本 `credits` 之和）与折合美元（kie 基础价 1 积分 = $0.005）。
7. 每个版本的 `file` 是产物的绝对路径，一个任务可能产出多个版本。用户选定后用 `genlab use` 设为当前版本；需要放进代码项目时自行复制该文件。

## 模型参数（-p）

- `key=value`：字符串；数字、布尔、数组按参数表自动转换。
- `key:=<JSON>`：JSON 值，如 `-p duration:=5`。
- 同键重复即数组，如 `-p image_urls=@a.png -p image_urls=@b.png`。
- `@<路径>`：本机文件，自动上传；库里的产物直接用它的 `file` 路径。
- `@source`：AI 编辑的源版本文件，只能用在 `edit`。
- `@@`：字面量 `@`。

## 规则

- 生成消耗 kie 积分：先看价格，任务数、分辨率、时长按需设置。
- 不手动修改库里的 `asset.json`；改名、移动、删除整个素材由用户在 Finder 里操作。
- 输出为 JSON；错误写 stderr 的 `{"error": ...}`，警告为 `{"warning": ...}`。
- 项目、文件夹、素材的名字用英文。
- 首次使用先运行 `genlab init`。
